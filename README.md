# CSV Reformatter για PrestaShop

Μικρή PHP εφαρμογή χωρίς εξωτερικές βιβλιοθήκες. Μετατρέπει αρχεία CSV ή ODS
σε CSV εισαγωγής προϊόντων για PrestaShop 1.7, 8 και 9.

## Εκτέλεση

Απαιτεί PHP 8.1 ή νεότερο. Από τον φάκελο του project:

```sh
php -S localhost:8000
```

Ανοίξτε το `http://localhost:8000/index.php`.

Για ανάγνωση ODS απαιτούνται οι επεκτάσεις PHP `zip` και `dom`. Για την
αγγλική μετάφραση ρούχων απαιτείται επίσης η επέκταση `curl`.

## Μορφή εισόδου βιβλίων

Το αρχείο πρέπει να περιέχει 10 στήλες με αυτή τη σειρά:

1. Εκδότης
2. Επίπεδο
3. Σειρά
4. Τίτλος
5. Έτος
6. Συγγραφέας
7. ISBN
8. Τιμή λιανικής με ΦΠΑ
9. Περιγραφή
10. Εικόνες

Οι στήλες που δεν χρησιμοποιούνται σε κάθε τύπο βιβλίου εμφανίζονται δυναμικά
στη φόρμα.

## Μορφή εισόδου ρούχων

1. Κατασκευαστής
2. Τίτλος
3. Κωδικός
4. Σύνθεση
5. Κατηγορία
6. Τιμή
7. Περιγραφή
8. Εικόνες

Η πρώτη γραμμή επικεφαλίδων είναι προαιρετική. Στα CSV υποστηρίζονται `;`, `,` και TAB
ως delimiters και γίνεται αυτόματη ανίχνευση. Τα πεδία που περιέχουν delimiter
πρέπει να είναι μέσα σε διπλά εισαγωγικά, σύμφωνα με τον κανόνα CSV.

Οι τιμές εισόδου μπορούν να χρησιμοποιούν κόμμα ή τελεία ως δεκαδικό σύμβολο
(π.χ. `12,50` ή `12.50`). Η έξοδος χρησιμοποιεί πάντα τελεία και δύο δεκαδικά,
UTF-8 με BOM και `;` ως delimiter.

## Αγγλική εξαγωγή ρούχων

Ορίστε το Google AI Studio API key ως μεταβλητή περιβάλλοντος στον PHP server:

```text
GOOGLE_API_KEY=your_key
```

Εναλλακτικά υποστηρίζεται και `GEMINI_API_KEY`. Το προεπιλεγμένο μοντέλο είναι
`gemini-3.8-flash` και μπορεί να αλλάξει με τη μεταβλητή `GEMINI_MODEL`.
Η αγγλική εξαγωγή στέλνει για μετάφραση μόνο τον τίτλο και την περιγραφή, ενώ
διατηρεί την αγγλική σύνθεση όπως είναι στο ODS. Η ελληνική εξαγωγή μεταφράζει
μόνο τη σύνθεση από αγγλικά σε ελληνικά. Τα αποτελέσματα αποθηκεύονται προσωρινά
στη συνεδρία.

Κάθε εργασία μετάφρασης εκτελείται αρχικά με μία ενιαία κλήση για όλο το
αρχείο. Αν η απόκριση αποτύχει ή δεν περιέχει όλα τα προϊόντα, γίνεται αυτόματο
fallback σε μικρότερα batches.

Η προαιρετική επιλογή «Διόρθωση κεφαλαίων τίτλων με AI» εντοπίζει μόνο τίτλους
που είναι κυρίως κεφαλαίοι και τους μετατρέπει σε φυσική ελληνική γραφή,
αποκαθιστώντας τους τόνους και διατηρώντας μάρκες, κωδικούς και κύρια ονόματα.

## Ροή

- Upload και βασικές ρυθμίσεις.
- Αναλυτικός έλεγχος ανά γραμμή και κελί.
- Αυτόματη εφαρμογή μόνο ασφαλών διορθώσεων και download.

Αμφίσημες τιμές (π.χ. `1.234`) δεν διορθώνονται αυθαίρετα: εμφανίζονται ως
σφάλμα ώστε να επιβεβαιωθούν στο αρχικό αρχείο.
